# Inflation and Interest Rate Project

This project analyzes the relationship between inflation and interest rates
using ARDL and ECM models.

Project structure:

data/
raw data

scripts/
01_build_dataset.R
02_stationarity_tests.R
03_ardl_model.R
04_ecm_model.R
05_diagnostics.R
06_plots.R

results/
generated outputs

paper/
research paper files

To run the project:

source("run_project.R")

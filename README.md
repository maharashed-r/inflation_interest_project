# Inflation and Interest Rate Dynamics (historical project)

> **Status: PRESERVED HISTORICAL RESEARCH PROJECT — SCIENTIFICALLY AUDITED.**
>
> This repository keeps the original project (baseline commit `cb61ead`, 12 March 2026)
> so that it stays reproducible and auditable. A scientific audit in September–October 2026
> found methodological and reproducibility limitations, documented in
> [docs/SCIENTIFIC_LIMITATIONS.md](docs/SCIENTIFIC_LIMITATIONS.md). The estimates here are
> **associations from time-series regressions, not validated causal effects**, and the
> project is **not ready for publication**. The original data, code, tables, figure and
> manuscript are kept unchanged in content.
>
> This project is **not the basis** of any later study. Planned follow-up research is a
> separate project and is not part of this repository.

## What the project did

| Item | As implemented in the code |
|---|---|
| Question (as stated in the manuscript) | The relationship between inflation and interest rates, using ARDL and an error-correction model |
| Geography | United States. This is not stated in the manuscript; it follows from the FRED series used (see [provenance](docs/provenance/DATA_PROVENANCE.md)) |
| Input data | `data/data.csv`, monthly 1947-01 to 2026-01: CPI (`CPIAUCSL`), effective federal funds rate (`FEDFUNDS`), nominal GDP (`GDP`, quarterly values in the first month of each quarter) |
| Method | ARDL with automatic lag selection (`ARDL::auto_ardl`, AIC), bounds F-test (case 3), unrestricted and restricted ECM, Durbin-Watson, Breusch-Pagan, HC standard errors, CUSUM |

The code contains **two different specifications**. They are not one analysis:

| Specification | Scripts | Data | Model | Outputs |
|---|---|---|---|---|
| **Quarterly, three variables** | `scripts/02`–`07` (run by `run_project.R` steps 1–7) | 1954Q3–2025Q4, N = 286 | `Inflation ~ Interest_Rate + GDP`, maximum lags (4,4,4) | Printed to the console only, plus `figures/cusum_stability_test.png` |
| **Monthly, two variables** | `scripts/08_tables.R` (step 8) | 1954-07 to 2026-01, N = 853 after lags | `inflation ~ interest`, maximum lags (4,4) | All files in `tables/` |

The manuscript (`paper/`) describes a third version (quarterly data with GDP *growth*). That
version is not implemented. See [SCIENTIFIC_LIMITATIONS.md](docs/SCIENTIFIC_LIMITATIONS.md).

## Repository structure

```
data/data.csv                  input data (provenance partly unknown)
scripts/00_packages.R          loads packages (stops with a message if any is missing)
scripts/install_packages.R     one-time package installation (not part of the pipeline)
scripts/01_data_cleaning.R     legacy; its result is not used later
scripts/02_build_dataset.R     builds results/final_dataset.csv (quarterly)
scripts/03-07_*.R              quarterly tests, ARDL, ECM, diagnostics, CUSUM figure
scripts/08_tables.R            monthly specification; writes tables/*
run_project.R                  runs steps 0-8 in order
results/final_dataset.csv      quarterly analytical dataset (generated)
tables/                        committed tables (generated by scripts/08)
figures/                       committed CUSUM figure (generated by scripts/07)
paper/                         original manuscript (Rmd and rendered docx)
tools/reproduce_and_verify.R   re-runs everything in a temporary copy and compares
docs/                          audit, limitations, provenance, environment
renv/, renv.lock               original renv files (records R 4.5.2 only)
```

Files were deliberately **not moved**: the scripts use these paths, and moving them would
change the historical code.

## Reproducing the results

Requirements: R (the original author used R 4.5.2; the outputs were also reproduced with
R 4.3.3) and the packages in `scripts/install_packages.R`. The versions that reproduced the
committed outputs are listed in [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md).

1. Open the project root (the folder with `inflation_interest_project.Rproj`) as the working
   directory.
2. Install the packages once: `source("scripts/install_packages.R")`.
3. **Check the committed outputs without overwriting them** (recommended):

   ```
   Rscript tools/reproduce_and_verify.R
   ```

   This copies the project to a temporary folder outside the repository, runs the whole
   pipeline there, and compares every generated table, the dataset and the figure with the
   committed files.
4. Or run the pipeline in place, which **overwrites** `results/`, `tables/` and `figures/`:
   `Rscript run_project.R`.

Result of the closure validation (October 2026): the dataset and all six CSV tables were
reproduced **byte-identically**. The two HTML tables match cell by cell. The figure was
regenerated with the same values; its bytes differ because of the graphics device. See
[docs/audit/REPRODUCTION_VALIDATION.md](docs/audit/REPRODUCTION_VALIDATION.md).
